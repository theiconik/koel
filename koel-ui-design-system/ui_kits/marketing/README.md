# Marketing UI Kit

Recreation of koel's marketing surface — the face of the brand.

- `index.html` — landing page (hero → social proof → how it works → quote → pricing → footer)
- `Components.jsx` — `Nav`, `Hero`, `HeroCard`, `LogoStrip`, `HowItWorks`, `Quote`, `Pricing`, `PricingRow`, `Footer`, plus atoms (`Button`, `KoelWordmark`, `KoelLogo`, `Eyebrow`)

Uses `../../colors_and_type.css` for tokens. Pure React + Babel in the browser. No build step.

**Caveats.** No codebase or Figma was provided, so this is built from the brand brief + product description, not from existing production UI. Swap the copy / imagery once real content exists.
